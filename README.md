# 🔐 Генератор паролей

Консольная программа на Python, которая создаёт случайные пароли по заданным параметрам.  
Вы сами выбираете длину, количество паролей и набор символов: цифры, строчные и прописные буквы, специальные знаки.  
Также можно исключить неоднозначные символы (`i`, `l`, `1`, `L`, `o`, `0`, `O`), чтобы пароль было легче читать.

---

### 🎮 Как пользоваться
Программа спросит количество паролей для генерации.

Затем длину каждого пароля.

Далее нужно ответить да или нет на несколько вопросов:

Включать ли цифры 0123456789?

Включать ли прописные буквы ABCDEFGHIJKLMNOPQRSTUVWXYZ?

Включать ли строчные буквы abcdefghijklmnopqrstuvwxyz?

Включать ли специальные символы !#$%&*+-=?@^_?

Исключать ли неоднозначные символы il1Lo0O?

После этого программа выведет готовые пароли.

⚠️ Важно: если вы ответите нет на все вопросы о наборе символов, программа не сможет сгенерировать пароль (не из чего выбирать). Выбирайте хотя бы один тип символов.

---

### 💬 Пример работы

Количество паролей для генерации? 3

Длина пароля? 8

Включать ли цифры 0123456789? да

### 🧠 Особенности реализации
Модуль random используется для выбора случайных символов без повторений внутри одного пароля (функция random.sample).

Проверка ответов да/нет вынесена в отдельную функцию check_for_yes_or_no().

Набор допустимых символов формируется динамически в переменной char.

Исключение неоднозначных символов выполняется через генератор списка.
